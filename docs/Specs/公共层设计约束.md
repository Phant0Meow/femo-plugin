# 公共层设计约束（单页）

> 性质：femo2host 公共层的**操作性约束汇总**——把散在守则与总纲里的裁决收成一页，动公共层之前过一遍。
> 本文是操作面摘要；裁决依据与作者原话住在源文档（出处随条标注），两边打架以原话为准。
> 读者：改 femo2host/ 的人，以及要在宿主侧新建「公共件候选」的人。

## 一、这段代码归谁——归属三问

对任何候选代码依次问：

1. **换个宿主，这段话还成立吗？** 成立 → 公共层；不成立 → 宿主。
2. **它持有物理形态吗？**（内存/文件/进程/会话）持有 → 形态件，留宿主；只做判断和翻译 → 协议件，进公共层。
3. **它重复了几次？** ≥2 且语义必须一致 → 必须合并，否则必然漂移；=1 → 先等第二个消费方出现再收，否则是假公用。

（出处：ARCHITECTURE §4.1「唯一的裁决标准」。）

## 二、收编判据（2026-09-24 用户判据）

- **公共层已有的、别宿主又抄一遍的 → 不追**（宿主侧债宿主自取）。
- **公共层缺的、≥2 宿主都在写的 → 收**。
- **只有一家用的大额私产 → 下推回那家**——公共层只放大家共用的（公共客厅不放大额私人日记）。
- 「只有一份的先别急着抽公共，等第二个用的人出现」（两把尺子的反面）。

案例对照：hub 喂送协议机收了（dsh 全量机制 + zcode 手搓简版已冒头 = ≥2）；名册公告队列没收（当期仅 dsh 一家在写，挂账等 zcode 名册动工）。

## 三、依赖方向（只准向下）

- 宿主只准消费 femo2host 门面与公共层，**不深入引擎内部**；引擎只从唯一门面（femo_api.py）被触碰。
- 公共层**不依赖任何宿主**；基础件谁都能用，谁也不许为了单例、动词、类型反向依赖调度层。
- 循环依赖零容忍：互抓的两个件拆出第三个件（如 dsh 的 sse.ts/verbs.ts 解环刀）。

## 四、上移纪律（改壳不改面）

- 宿主实现上移时，**原地留薄壳再导出，对外接口一字不变**——所有既有使用方零改动，这是验收标准。
- 再导出类用**空子类**：`export const X = CoreX` 丢实例类型（TS2749）；`export class X extends CoreX {}` 值与类型双保。
- 公共层与宿主的接缝**全部是注入式回调**，契约写在公共层文件头（如分诊台的 board/verbs/skip、喂送机的 feedUrl/source/sessionAddr）。
- 上移前先查引用面：硬编码路径、镜像白名单、测试、同步脚本，逐处 grep 清零。

## 五、语言与形态

- 公共层**纯 ESM .mjs**，不用 TypeScript；类型用 JSDoc + 伴生 `.d.mts`（dsh typecheck 与 IDE 都吃它）。
- dsh 的 esbuild 直接 bundle .mjs；zcode/autoclaw 裸 mjs 动态 import（三档布局探测：开发态嵌套/安装态平铺）。
- 「唯一答案」类解析（地址、路径、身份）**函数化懒读**——模块顶层读 env/文件会锁死启动时的值。
- 行为面变更须考虑**多宿主同款换轨**：新公共件落地后，已有第二份手搓实现的宿主应当场换轨，不让第二份活过夜。

## 六、测试与验证底线

- **FEMO_DATA_DIR 沙盒三通道**：引擎 DB、驿站、投影账本全进沙盒——漏任何一条，测试的信与场次漏进生产被钩子当真通知。
- 每刀：构建通过 + 类型对基线（只减不增）+ 相关单测全绿 + 受影响端冒烟；行为面变更 3081 重启武装（先查活再重启）+ 真演出目检上帝窗。
- **三份同步**：开发仓 → dist → 安装缓存（真正生效的副本）。
- bundle 特征串核对：中文按转义形态搜，直搜必漏。

## 七、快速判决（动手前自问）

- 这段逻辑换一个宿主还成立吗？→ 成立：公共层；不成立：适配器。
- 它是「判断/翻译」还是「持有形态」？→ 前者公共层优先；后者永远是宿主的。
- 同样的语义已经有几份了？≥2 必须合并；=1 先等第二个消费方。
- 公共层已有的、别宿主重抄的 → 不追；公共层缺的、≥2 宿主在写的 → 收。
- 新增引擎事件？→ 分诊表加一行（公共层），落点各宿主自接；要通知导演/演员的，常驻引擎产信进驿站，不走路由器。
- 新增工具？→ 总纲加规格与执行体，两边注册壳零改动自动获得。
- 写测试？→ 先确认 FEMO_DATA_DIR 三通道都进沙盒。
