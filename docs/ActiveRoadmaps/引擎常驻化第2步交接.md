   重放环+心跳）+归属闸。适配器与 473 项测试全程冻结。

## 五、本窗实测出的皱褶（清单没写、实施时必碰）

1. **EventProjector 的 set_host 是进程级单值**。daemon 一座进程服务多宿主，
   段键归属靠 dispatch_facts（(job,soul)→host，产信端在记）没问题，但
   `_seg_ref` 给「只报 wait_key 的帧」合成键时用喂行来源——daemon 进程内
   谁是 source？实施时把「帧的宿主上下文」随事件带进装配段，别拿 daemon
   自称顶（会重演标错宿主的老病）。
2. **信任账/owner 登记在进程内直连后走 `_hub_owner` 读档案 host_refs**
   （多宿主格全量登记已实现），比 HTTP 面简单，但别绕过 `_foreign_owner_row`
   的会话过滤。
3. **_mailbox_post 的 foreign_pickup 分支查 hub.cast_job**——daemon 里
   hub 就在隔壁，注意别把「进程内调用」写成「自己 POST 自己」。
4. **投影页/dsh 投影窗的人类席**：刀2d 缓行项（清单 §十一），第 2 步端点
   搬进 daemon 时一并做——席位自写信封+哑投信口。
5. **测试泄漏治理已成体系**：conftest 三个件（FEMO_PROJECTION_PORT=0 护栏/
   sessionstart 清扫/_kill_sandbox_daemon 收尸）+ 七处台架 close 按 hub.json
   pid 收尸。第 2 步新增桥级测试照抄这套；daemon 级测试学 test_hub_unify
   （它自己收自己的 daemon）。
6. **全量 pytest 现在 12-15 分钟**（每座测试桥多一次 daemon 冷启）；失败
   画像基线：town_structure+par_exit=挂账旧债，join_wiring/variables/
   mail_catchup/mind=顺序抖动（单跑即绿）。跑测必设 FEMO_DATA_DIR，本窗
   用的 basetemp=cache/pytest-tmp。
7. **3081 的启动脚本坑**：_femo_hubfeed_restart_3081.ps1 会**字面杀全桥**
   （连 3083 新桥和 deepseekweb 桥一起杀）；同一 home 并发多次启动=集体
   僵死不绑端口，须按 pid 杀光再单次拉起；alpha.2 冷启动在 1874 会话的大
   home 要数分钟勿过早判死。
